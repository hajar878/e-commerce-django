# E-commerce Django

## Description
Application e-commerce développée avec Django.

## Technologies
- Python
- Django
- HTML
- CSS
- Bootstrap
- SQLite

## Fonctionnalités
- Authentification
- Catalogue des produits
- Panier
- Commandes
- Paiement

## Installation

pip install -r requirements.txt

python manage.py migrate

python manage.py runserver
